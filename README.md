# Technology Animation

A small, responsive technology-themed animation built using plain HTML, CSS and JavaScript.

![Demo screenshot](https://raw.githubusercontent.com/BinaryVortex/Technology-Animation/main/Screenshot%202024-08-25%20144927.png)

## Overview

This repository contains an animated UI showcasing technology/brand icons and subtle motion effects. It is implemented with semantic HTML, CSS (the majority of the code) and a small amount of JavaScript for interactivity.

## Features

- Lightweight, dependency-free animation
- Pure HTML/CSS layout and animations
- Easy to read and modify styles in `style.css`
- Single static page (`index.html`) for quick preview

## Preview / How to view

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Technology-Animation.git

2. Open `index.html` in your browser (double-click or use a local server).

Alternatively you can view the demo by enabling GitHub Pages for this repository and serving the `main` branch.

## Files

- `index.html` — markup for the animation
- `style.css` — styles and keyframe animations (primary code)
- `Screenshot 2024-08-25 144927.png` — demo screenshot (shown above)

## Customize

- Edit `style.css` to change colors, timing, and layout.
- Add or replace icons/graphics in the HTML to adjust the visual content.
